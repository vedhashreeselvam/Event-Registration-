# Event Registration Web Page

A simple **Event Registration Web Page** created using **HTML**.
This project is designed for beginners to understand how HTML forms are used to collect user information for event registration.

## 📌 Features

* Name input field
* Email input field
* Phone number input field
* Event selection option
* Simple and clean registration form
* Submit button for registration

## 🛠️ Technologies Used

* HTML5

## 📂 Project Structure

```text
Event-Registration/
│
├── index.html
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Fill in the registration details and submit the form.

## 🎯 Purpose

The main purpose of this project is to practice **HTML forms, input fields, labels, and basic webpage structure**.
